# anrazvan.github.io

My personal site, served by GitHub Pages at <https://anrazvan.github.io>.

| Path | What it is |
|---|---|
| `index.html` | Landing page. **Replace this with the CV** when it's ready — nothing else depends on it. |
| `bountytasks/privacy/index.html` | Privacy policy for the BountyTasks app. The URL given to Google Play. |
| `app-ads.txt` | Tells ad networks that AdMob publisher `pub-9076875777318884` is allowed to sell ads in BountyTasks. **Must stay at the root of the domain** or AdMob limits ad serving. |
| `.nojekyll` | Serves the files as they are, without running Jekyll over them. |

Plain HTML, no build step: edit a file, commit, push, and it's live within a minute.
